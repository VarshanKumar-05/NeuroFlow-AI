# Contributing to NeuroFlow AI

Thank you for your interest in contributing to **NeuroFlow AI**! We welcome contributions from developers, researchers, and open-source enthusiasts.

---

## How to Contribute

### 1. Reporting Bugs
- Search existing issues before creating a new bug report.
- Include OS version, Python/Node versions, and steps to reproduce.

### 2. Suggesting Enhancements
- Open a feature request issue with a detailed explanation of the proposed functionality and architectural impact.

### 3. Pull Request Process
1. Fork the repository (`https://github.com/VarshanKumar-05/NeuroFlow-AI.git`).
2. Create a feature branch: `git checkout -b feature/amazing-feature`.
3. Ensure code formatting adheres to PEP8 (Python) and ESLint/Prettier (React).
4. Run frontend build verification: `cd frontend && npm run build`.
5. Run backend syntax check: `python -m py_compile backend/app/main.py`.
6. Commit changes: `git commit -m 'feat: add amazing feature'`.
7. Push to branch: `git push origin feature/amazing-feature`.
8. Open a Pull Request against the `main` branch.

---

## Code Style & Conventions
- **Python**: PEP 8 guidelines with type annotations where appropriate.
- **TypeScript / React**: Modern functional components with React Hooks and TypeScript interfaces.
- **Commit Messages**: Conventional Commits style (`feat:`, `fix:`, `docs:`, `refactor:`, `test:`).
