# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :x:                |
| < 5.0   | :x:                |

## Reporting a Vulnerability

We take the security of **NeuroFlow AI** seriously. If you discover a security vulnerability, please do NOT open a public GitHub issue.

Instead, please report the vulnerability privately by emailing:
**`varshankumar05@gmail.com`**

Please include:
1. Description of the vulnerability and potential impact.
2. Steps to reproduce or proof-of-concept code.
3. Suggested fix (if available).

We will acknowledge receipt of your report within 48 hours and provide regular updates regarding resolution.
